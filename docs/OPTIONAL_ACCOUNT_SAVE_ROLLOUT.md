# 전 게임 선택형 ChatGPT 계정 저장 적용

사용자 요청 (2026-10-22): 13개 모두 로그인 없이 플레이/로컬 저장, ChatGPT 로그인은 선택형 서버 저장용으로만 사용. 게임 목록에 공통 안내. 현재 전체 구현 완료 아님.

## 현재
- 계정 저장 구현: rose-spire, prism-muse, muse-studio, companion-guild, ember-tactics (5개).
- 추가 필요: hunt-now, beauty-deck, srpg-prototype, rune-territories, aster-hunt, last-archive, fogbound-tactics, world-breaker (8개).
- GitHub Pages에는 서버/ChatGPT 인증 API가 없음. 로그인 버튼이나 문구만 추가해도 서버 저장이 생기지 않음.
- Sites 공개 방문과 선택형 계정 저장은 별개. 공개 방문 유지, 서버 읽기/쓰기는 인증된 사용자 ID별로 제한.

## 완료 조건
1. 기존 URL, 키, 저장 스키마, 해금과 누적 성장 보존. IndexedDB 게임 포함.
2. 초기 API 401/오프라인/타임아웃이어도 로컬로 즉시 시작. 서버 장애가 플레이를 막지 않음.
3. 로그인은 명시적인 상위 탐색 링크로 선택. 성공 후 기존 로컬/서버 기록을 비교하고 선택 없이 덮어쓰지 않음.
4. 충돌/계정 전환/빈 서버/저장 실패/구형 세이브 회귀 검사. 사용자별 데이터 격리, revision 확인, 로컬 백업 유지.
5. GitHub 원본 변경과 실제 호스트 배포를 둘 다 수행. 서로 다른 호스트로 옮길 경우 내보내기/가져오기와 기존 기록 이전 경로를 먼저 구현.
6. 비로그인 시작→진행→새로고침, 로그인 서버 저장→다른 기기 불러오기, 다른 계정 격리 검증. 미실행은 미실행으로 보고.
7. 실제 배포와 검증이 끝난 게임만 games.json cloudSave를 supported로 변경. 계획 상태는 planned.

## 이번 반영
- 목록 공통 플레이/로컬/선택형 ChatGPT 서버 저장 안내.
- 현재 5/13 지원을 명시. 나머지는 계정 저장 추가 예정으로 정직하게 표시.
- 원본 저장소/커밋은 접힌 개발 정보로 이동. 복사본 경고는 중복 노출 제거, 기존 데이터/주소 유지.
- 게임 본체 서버 저장을 추가한 변경은 아님. 본 작업을 13개 계정 저장 완료로 보고하지 말 것.
